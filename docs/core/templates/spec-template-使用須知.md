# 規格文件模板使用須知

本文件不要貼進 Plane.io,只給填寫者(企劃)自己看。實際要貼進 Plane 的內容是 `spec-template.md`。

1. `spec-template.md` 對應核心規範第7節「規格書撰寫規範」,由企劃填寫,PM協同確認,平台與遊戲專案共用同一份模板。
2. 內容可直接複製貼上到 Plane.io 對應工作項的描述欄,Plane 會完整呈現 markdown 格式與表格。
3. **`spec-template.md` 第一行必須是 `# 規格文件:【需求名稱】` 這個大標題**——貼到 Plane 時 Plane 會把第一行拿去當頁面標題,前面不要加任何內容(包含註解、空行),否則頁面標題會變成「Untitled」。這是實際踩過的坑,詳見 `~/.claude/logs/pitfalls.md`(2026-08-11條目)。
4. 第7節「影響評估」為必填,凡涉及金額/機率/賠付的功能,測試階段須附驗證方式(對應核心規範第12節不可妥協要求)。
5. 缺料寫「not_stated」,不要腦補;查得到的先查,查不到才標。

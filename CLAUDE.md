# Development_Process

## Agent skills

### Issue tracker

Local markdown under `.scratch/<feature-slug>/` (no git remote in this repo). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context, but decision records live at `docs/decisions/` (root) plus `docs/core/decisions/`, `docs/platform/decisions/`, `docs/game/decisions/` (tier-specific) instead of a generic `docs/adr/`. See `docs/agents/domain.md`.
